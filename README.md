### About

I build custom platforms that help fitness coaches monetize the 99% of their audience that will never pay for premium coaching. Think $10-20/mo subscriptions at scale, not $200/mo 1:1 coaching.

Currently working with Spanish-speaking coaches with 20K+ followers, replacing generic tools like TrueCoach with tailored platforms under a revenue-share model. I only get paid when the system generates results.

My background is full-stack development, but I think in funnels, conversion gaps, and unit economics first — then write the code.

### How I think about building

```
1. Audit the conversion gap → quantify lost revenue
2. Design the system → not features, revenue architecture
3. Ship fast → imperfect action > perfect paralysis
4. Measure → only build what moves the number
5. Revenue share → I win when you win
```
